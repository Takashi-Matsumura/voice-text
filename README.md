# Voice Text - 音声文字起こしアプリ

ブラウザの Web Speech API を使ったリアルタイム音声文字起こしアプリです。
スペースキーを押している間だけ録音し、離すと文字起こし結果が表示されます。

## 機能

- **Push-to-talk 方式** - スペースキー長押しで録音、離すと停止。録音中の音声はバッファリングされ、スペースを離した時点でまとめて1つのエントリとして確定します（途中の無音で分割されません）
- **日本語 / 英語 切り替え** - ヘッダーから言語モードを切り替え可能
- **リアルタイム表示** - 認識中のテキストをリアルタイムでプレビュー表示（確定前のバッファ内容 + 現在の中間結果）
- **新しい順に表示** - 最新の文字起こし結果が常に画面上部に表示
- **辞書機能** - 文字起こし結果のテキストを選択して辞書に登録すると、以降の文字起こしで自動的に置換されます。ヘッダーの `DICT` ボタンで辞書パネルを開閉
- **AI バディ（ぶたキャラ）** - 文字起こしを監視してランダムにツッコミを入れてくれる相棒機能。ASCII アートのキャラクターと吹き出し UI でタイムラインに自然に溶け込みます
- **デバッグモード** - ヘッダーの `DEBUG` ボタンで、LLM サーバの状態・リクエスト / レスポンスの中身・レイテンシなどをフローティングパネルに表示

## AI バディについて

画面の端にいる小さなぶたのキャラクターが、あなたの文字起こしをこっそり読んでいて、たまに一言ツッコミを入れてくれます。

- ローカルで動く [llama.cpp](https://github.com/ggerganov/llama.cpp)（gemma4 モデル）をバックエンドに利用
- `/api/buddy` エンドポイント経由で文字起こしを LLM に渡し、短いコメントを生成
- ツッコミはタイムラインに吹き出しとして表示され、会話の流れを邪魔しません

バディ機能を有効にするには、ローカルで llama.cpp サーバ（`llama-server`）を `http://localhost:8080` で起動しておいてください。macOS では `~/Library/LaunchAgents/` に launchd の plist を置いておくと、ログイン時に自動起動させることもできます。

## デバッグモード

ヘッダー右上の `DEBUG` ボタンを押すと、右下にデバッグパネルが開きます。

- **llama.cpp サーバ状態**: 接続可否（UP / DOWN）、エンドポイント URL、疎通レイテンシ、ロード済みモデル一覧
- **直近のバディ呼び出し**: タイムスタンプ、モデル名、HTTP ステータス、レイテンシ、リクエストパラメータ（`max_tokens`, `temperature`）
- **リクエスト内容**: system / assistant / user の全プロンプト（折りたたみ）
- **生レスポンス**: llama.cpp から返ってきた生の JSON（折りたたみ）
- **表示判定**: LLM が生成した応答が抽選（通常モードは約 40% の確率）を通って画面に出たかどうか

デバッグモードが有効な間は、抽選を無効化して LLM の応答を **必ず** タイムラインに表示します。通常モードに戻すと抽選は元の確率に戻ります。

## セットアップ

```bash
npm install
npm run dev
```

http://localhost:3000 をブラウザで開いてください。

> **注意:** Web Speech API は Chrome / Edge で動作します。Safari や Firefox では対応していない場合があります。

## 使い方

1. ブラウザで http://localhost:3000 を開く
2. ヘッダーの言語ボタンで「JP 日本語」または「EN English」を選択
3. スペースキーを押し続けながら話す
4. スペースキーを離すと文字起こし結果が表示される
